# 教师试用与反馈方案

## 建议对象

邀请8–15位校内教师进行试用，尽量覆盖金融工程、金融科技、投资学、风险管理等方向。

## 建议试用任务

1. 查找一个可用于期权教学的行业资源。
2. 查找一个AI或机器学习金融应用资源。
3. 查找一个可用于Python实验的工具。
4. 按学习路径选择下一步自主学习内容。

## 简短反馈问卷

1. 资源分类是否清晰？（1–5）
2. 查找资源是否方便？（1–5）
3. “教学价值”和“建议用途”是否有帮助？（1–5）
4. 学习路径是否适合教师自主学习？（1–5）
5. 是否愿意继续使用或推荐该平台？（1–5）
6. 最希望新增哪些资源或功能？（开放题）
7. 使用过程中遇到的主要问题是什么？（开放题）

## 结项留痕

建议保存教师名单（经同意）、测试时间、问卷结果汇总、典型建议、修改前后截图和更新日志，形成“测试—反馈—优化”的证据链。
