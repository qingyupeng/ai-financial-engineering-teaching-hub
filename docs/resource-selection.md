# 资源筛选与评价说明

## 一、基本原则

平台不以“名校数量”或“资源数量”为目标，而以**教师能否真正拿来使用**为核心标准。每项资源必须经过“来源核验—实质内容检查—课程相关性判断—教学价值提炼—使用建议”五个步骤。

只有课程名称、项目培养方案或简短课程介绍，而缺乏课件、讲义、代码、习题、考试、视频、数据、Notebook、案例或可操作学习材料的页面，不作为主资源库前台精选。此类页面可保留在后台，用于课程体系对标或后续复核。

## 二、内容优先级

以下 S / A / B 仅表示**编辑筛选优先级**，与网站卡片展示的100分资源评分不是同一套等级体系。

### S级：可直接用于教学或教师能力建设

具备多种实质材料，例如：

- 讲义 / Slides / 教材章节
- Python / R / MATLAB代码或Notebook
- 数据集或API
- 习题、作业、考试及答案
- 视频课程或连续专题
- 完整案例、交易模拟或实验说明
- 可复现项目、科研工作流或教学活动设计

这类资源优先进入前台精选。

### A级：具有明确可操作内容

有较完整的教程、课程资料、官方文档、案例或代码，但材料类型没有S级丰富。适合教师自学或转化为课程内容。

### B级：导航或补充资源

资源本身有价值，但主要起入口、导航、课程体系对标或背景补充作用，原则上保留在后台候选库。

### 不进入前台精选

仅有课程名称、项目介绍、培养方案、一两段课程简介、普通产品功能说明、提示词合集或浅层操作指南，无法支持教师实际备课、自学、实验、课程设计或科研工作流建设的页面。

## 三、100分评价框架

网站统一用100分制展示资源评分：

- **实质教学资源丰富度：30分**
- **与《金融工程》课程的直接相关度：20分**
- **教学可直接使用/改造程度：20分**
- **来源权威性：10分**
- **AI或计算方法融合程度：10分**
- **获取便利性：5分**
- **时效性：5分**

其中，“实质教学资源丰富度”是首要指标。评分用于同类资源比较，不替代人工判断；第三至第五专区均采用高门槛替换制。

## 四、排序与前台准入

1. 前台精选资源必须进入 `data/curation.json` 的 `featured_order`。
2. 完整课程材料、代码、Notebook、习题、数据、案例和系统工作流优先。
3. 一般官方门户、重复Quick Start、组织导航资源和教学增量较低的条目进入后台候选库。
4. 纯培养方案/项目介绍不进入前台精选。
5. GitHub stars、机构名气或工具流行度都不能单独构成前台准入理由。
6. 同一主题资源高度重合时，只保留代表性最强、材料最完整、维护最稳定的条目。

## 五、“案例”专区专项筛选标准

第四专区“案例”专指**金融业真实使用AI的案例**。原则上只有同时满足以下条件的资源才进入前台：

1. **金融业真实主体**：投行、商业银行、资管机构、对冲基金、量化投资机构、财富管理机构、证券交易或市场基础设施等。
2. **业务场景明确**：能够说明AI进入了投研、交易、定价、风险管理、KYC、财富顾问、合规、市场监测等哪个具体流程。
3. **AI应用方式可识别**：例如机器学习、生成式AI、RAG、LLM Agent、多智能体、预测模型或异常检测，而不是只有“数字化”“智能化”等泛表述。
4. **一手来源优先**：机构官网、年报、官方产品页、官方研究或新闻稿优先；二手媒体只能作为补充验证。
5. **有可讨论结果或机制**：最好能提供效率、使用规模、处理量、工作流变化等结果；若没有量化指标，也必须清楚说明业务机制。
6. **具有教学增量**：能够形成课堂讨论问题，如人机协作、模型风险、过拟合、幻觉、合规、可解释性、隐私、权限、审计或组织流程再造。
7. **不收泛材料**：交易所投教、金融知识页、市场数据入口、一般AI行业观点、仅讨论“投资AI股票”的内容不属于本专区。

案例专区保持少量高质量代表案例，新增案例采用**高质量替换制**。

## 六、“AI赋能教学”专区专项筛选标准

第五专区以“高校教师能否直接用于教学或科研能力建设”为核心，不以某款AI产品是否流行为标准。前台资源原则上应满足以下多数条件：

1. **体系完整**：具有完整课程、连续专题、系列视频、系统讲义或成套Notebook，而非单一功能介绍。
2. **可直接复用**：提供作业、课堂活动、项目设计、评分rubric、AI使用政策、案例或可执行研究工作流中的一种或多种。
3. **覆盖真实工作流**：能够进入备课、课堂、评价、科研选题、文献、数据分析、模型构建、写作、核验等完整环节，而不是只展示“怎样提问”。
4. **高校教师迁移价值明确**：资源可以合理迁移到金融、经济或社会科学课程与科研场景。
5. **来源可靠**：优先高校、研究机构、作者本人或正式开源项目的一手入口。
6. **重视可靠性与责任边界**：对核验、学术诚信、数据安全、隐私、人类监督或AI使用政策有明确讨论。
7. **不收凑数资源**：普通产品帮助页、提示词合集、营销型“用例大全”和浅层操作指南原则上不进入前台。

本专区保持精简，并以《智能体与社会科学研究》等体系化资源作为质量参照，新增资源实行替换制而非持续累加。

## 七、二次加工要求

每项主资源至少增加两类平台原创信息：

1. **教学价值**：说明该资源为什么值得《金融工程》教师阅读或使用。
2. **建议用途**：说明它适合哪个教学环节、课程模块或教师学习阶段。

对于“案例”专区，还应尽量提炼：**机构—业务流程—AI方法—业务价值—风险/治理问题**。

对于“AI赋能教学”专区，还应尽量说明：**适用教师任务—可复用材料—迁移方式—核验与责任边界**。

## 八、数据与维护校验

- 每项资源必须有标题、来源、专区、金融模块、AI主题、难度、语言、评分、教学价值、建议用途、URL和核验日期。
- 标题不得重复；URL必须为有效的 `http` 或 `https` 地址。
- 每项候选资源必须明确处于“前台精选”或“后台候选”之一。
- GitHub Pages部署前自动运行 `scripts/validate-data.mjs`；结构性错误会阻止错误版本发布。

## 九、版权与合规

对高校、金融机构和第三方网站的资源，以原始链接和导读为主。未经明确许可，不重新分发原始课件、付费资料或版权受限视频。
