# 资源筛选与评价说明

## 一、基本原则

平台不以“名校数量”或“课程名称数量”为目标，而以**教师能否真正拿来使用**为核心标准。每项资源必须经过“来源核验—实质内容检查—课程相关性判断—教学价值提炼—使用建议”五个步骤。

只有课程名称、项目培养方案或简短课程介绍，而缺乏课件、讲义、代码、习题、考试、视频、数据、Notebook、案例或可操作学习材料的页面，不再作为主资源库的重点资源。此类页面最多保留为“课程体系对标参考”，并在前台降权或隐藏。

## 二、主资源库优先级

### S级：可直接用于教学

具备多种实质材料，例如：

- 讲义 / Slides / 教材章节
- Python / R / MATLAB代码或Notebook
- 数据集或API
- 习题、作业、考试及答案
- 视频课程
- 完整案例、交易模拟或实验说明
- 可复现的项目或教程

这类资源优先展示。

### A级：具有明确可操作内容

有较完整的教程、课程资料、官方文档、案例或代码，但材料类型没有S级丰富。适合教师自学或转化为课程内容。

### B级：导航或补充资源

资源本身较有价值，但主要起到入口、导航、课程体系对标或背景补充作用。默认靠后展示。

### 不进入主资源库

仅有课程名称、项目介绍、培养方案或一两段课程简介，无法支持教师实际备课、自学、实验或作业设计的页面。

## 三、100分评价框架

为纠正“来源权威但内容空泛也得高分”的问题，评价权重调整为：

- **实质教学资源丰富度：30分**
- **与《金融工程》课程的直接相关度：20分**
- **教学可直接使用/改造程度：20分**
- **来源权威性：10分**
- **AI或计算方法融合程度：10分**
- **获取便利性：5分**
- **时效性：5分**

其中，“实质教学资源丰富度”是首要指标。

## 四、排序规则

1. 项目组人工认定的重点教学资源优先。
2. 在同一层级内，完整课程材料、代码、Notebook、习题、数据和案例优先。
3. 一般官方门户和导航资源靠后。
4. 纯培养方案/项目介绍不进入主资源库前台。

## 五、二次加工要求

每项主资源至少增加两类平台原创信息：

1. **教学价值**：说明该资源为什么值得《金融工程》教师阅读或使用。
2. **建议用途**：说明它适合哪个教学环节、课程模块或教师学习阶段。

## 六、版权与合规

对高校、金融机构和第三方网站的资源，以官方链接和导读为主。未经明确许可，不重新分发原始课件、付费资料或版权受限视频。
