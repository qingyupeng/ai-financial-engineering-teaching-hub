# 资源筛选与评价说明

## 一、基本原则

平台不以资源数量为唯一目标。每项资源必须经过“来源核验—课程相关性判断—AI主题标注—教学价值提炼—使用建议”五个步骤。

## 二、评分框架

- 来源权威性：20分
- 金融工程相关度：25分
- AI融合程度：20分
- 教学可借鉴性：20分
- 获取便利性：10分
- 时效性：5分

A级（≥85）进入重点推荐；B级（70–84）进入常规资源库；C级仅作为补充。

## 三、二次加工要求

每项资源至少增加两类平台原创信息：

1. **教学价值**：说明该资源为什么值得《金融工程》教师阅读或使用。
2. **建议用途**：说明它适合哪个教学环节、课程模块或教师学习阶段。

## 四、版权与合规

对高校、金融机构和第三方网站的资源，以官方链接和导读为主。未经明确许可，不重新分发原始课件、付费资料或版权受限视频。
